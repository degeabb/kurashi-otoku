  • ကုမ္ပဏီပြောင်းပါက: လက်ရှိကုမ္ပဏီ၏ login ID/password (MNP One-Stop) သို့မဟုတ် MNP ကြိုတင်စာရင်းနံပါတ်

  • Rakuten Saikyo Plan (သို့မဟုတ် Saikyo U-NEXT) ကို လျှောက်ထားပြီး မိတ်ဆက် login ဝင်သည့်နေ့မှ နောက်ဒုတိယလကုန်မတိုင်မီ စတင်အသုံးပြုပါ
  • ထိုသတ်မှတ်ရက်မတိုင်မီ Rakuten Link အက်ပ်မှ ၁၀ စက္ကန့်ကျော် ဖုန်းခေါ်ပါ
  • တစ်ဦးလျှင် အများဆုံး လိုင်း 5 ခု။ Rakuten Group ဝန်ထမ်းကိုယ်တိုင် အကျုံးမဝင်ပါ။ ပွိုင့်ပမာဏသည် 2026 စက်တင်ဘာ 17 မှစ၍ လျှောက်ထားမှုများအတွက် ဖြစ်သည်

Plan ရွေးချယ်ပါ

“Rakuten SAIKYO Plan” ကို ရွေးပြီး “Start with Plan” ကို နှိပ်ပါ (ဂျပန်မျက်နှာပြင်တွင် 「プランを申し込む」)။ ဖုန်းပါ တစ်ပါတည်း ဝယ်လိုပါက ခလုတ်အပေါ်ရှိ “Apply for plan only or with a phone” လင့်ကို နှိပ်ပါ။ SIM ကတ် / eSIM ကို shopping cart ၏ SIM TYPE တွင် စစ်ဆေး သို့မဟုတ် ပြောင်းနိုင်သည်။

eSIM အကြံပြုချက်: eSIM ဖြင့်ဆိုလျှင် SIM ကတ်ရောက်ရန် စောင့်စရာမလိုဘဲ ဖွင့်နိုင်သည်။ ဖုန်းက eSIM ကို ပံ့ပိုးမပံ့ပိုး အရင်စစ်ဆေးပါ။

ကိုယ်ပိုင်အထောက်အထား စစ်ဆေးခြင်း

အလွယ်ဆုံးနည်းမှာ “スマホでかんたん本人確認” ဖြစ်သည် — my Rakuten Mobile အက်ပ် (Rakuten Link အတွင်း) တွင် ဖုန်းဖြင့် ကတ်ပြားရှိ IC chip ကို ဖတ်ပါ။ အသုံးပြုနိုင်သော ဓာတ်ပုံပါ စာရွက်စာတမ်းများ: ဂျပန်နိုင်ငံသားများအတွက် My Number ကတ် သို့မဟုတ် ယာဉ်မောင်းလိုင်စင်၊ နိုင်ငံခြားသားများအတွက် နေထိုင်ခွင့်ကတ် (在留カード) သို့မဟုတ် အထူးအမြဲတမ်းနေထိုင်ခွင့် လက်မှတ်။ 住民票 မိတ္တူကို စာတိုက်မှ ပို့နိုင်သော်လည်း ပိုကြာပါသည်။

အချက်အလက်ကို စစ်ဆေးပါ: အမည်နှင့် လိပ်စာသည် စာရွက်စာတမ်းနှင့် အတိအကျ တူရမည်၊ မတူပါက ပြန်ပို့ခံရမည်။

ဖုန်းနံပါတ် ရွေးချယ်ပါ

နံပါတ်မပြောင်းဘဲ ပြောင်းရွှေ့ခြင်း (MNP): ဆက်သုံးလိုသော နံပါတ်ကို ထည့်ပါ။ နံပါတ်အသစ်: ပြသထားသော နံပါတ် 3 ခုမှ ရွေးပါ (အခမဲ့) သို့မဟုတ် ယန်း 1,100 ပေး၍ နောက်ဆုံးဂဏန်း 4 လုံးကို ရွေးနိုင်သည်။

MNP ပြောင်းရွှေ့ရာတွင် သိထားရန်: လက်ရှိကုမ္ပဏီက MNP One-Stop ကို ပံ့ပိုးပါက MNP ကြိုတင်စာရင်းနံပါတ် မလိုပါ — လက်ရှိကုမ္ပဏီ၏ login ID နှင့် password ကိုသာ ပြင်ဆင်ထားပါ။ မပံ့ပိုးပါက MNP ကြိုတင်စာရင်းနံပါတ်ကို ကြိုယူထားပါ။ လက်ရှိကုမ္ပဏီရှိ စာချုပ်ပိုင်ရှင်အမည်သည် Rakuten Mobile လျှောက်လွှာနှင့် တူရမည်။

လက်ခံယူခြင်း၊ ငွေပေးချေခြင်းနှင့် ရွေးချယ်စရာများ

ပို့ဆောင်မည့်လိပ်စာ (စာရွက်စာတမ်းနှင့် တူရမည်၊ ပုံမှန် 1–3 ရက်အတွင်း ရောက်သည်) နှင့် ငွေပေးချေမှုနည်းလမ်း (ခရက်ဒစ်ကတ် သို့မဟုတ် ဘဏ်အကောင့်မှ နုတ်ယူခြင်း) ကို စစ်ဆေးပြီး “この内容で申し込む” (ဤအတိုင်း လျှောက်ထားမည်) ကို နှိပ်ပါ။

15 မိနစ် ဖုန်းခေါ်ဆိုမှု option (တစ်လ ယန်း 1,100) သို့မဟုတ် voicemail (တစ်လ ယန်း 330) ကို မရွေးပါက သတိပေး popup ပေါ်လာမည်။ မလိုအပ်ပါက “加入せずに次へ” (မထည့်ဘဲ ဆက်သွားမည်) ကို နှိပ်ပါ။

ငွေချွေတာရန်: Rakuten Link အက်ပ်မှ ဂျပန်ပြည်တွင်း ဖုန်းခေါ်ဆိုမှုများ အခမဲ့ဖြစ်သောကြောင့် လူအများစုသည် ဖုန်းခေါ်ဆိုမှု option မလိုအပ်ပါ။

Rakuten Mobile ကို သုံးနေပြီးသားပါ။ ပွိုင့်ရနိုင်ပါသေးသလား?

မိတ်ဆက်လင့်ကို အရင်မဖွင့်ဘဲ လျှောက်ထားမိပါပြီ။ ဘာလုပ်ရမလဲ?

တရားဝင်စည်းမျဉ်းတွင် ဖော်ပြထားသော campaign အချို့ (ဥပမာ iPhone လျှော့စျေးအချို့) နှင့်သာ တွဲသုံးနိုင်သည်။ လျှောက်ထားမီ campaign စည်းမျဉ်း (campaign code 2162) ကို စစ်ဆေးပါ။

စတင်အသုံးမပြုခြင်း၊ ငွေမပေးချေခြင်း သို့မဟုတ် ပွိုင့်အတွက်သာ စာချုပ်ချုပ်သည်ဟု သတ်မှတ်ခံရပါက (ဥပမာ အတိုချုပ် ဖျက်သိမ်းခြင်းကို ထပ်ခါထပ်ခါ ပြုလုပ်ခြင်း) ပွိုင့်မရနိုင်ပါ။

လျှောက်ထားရန် အဆင်သင့်ဖြစ်ပြီလား?

ဝန်ထမ်းမိတ်ဆက်လင့်မှတစ်ဆင့် လျှောက်ထားပြီး ပွိုင့် အများဆုံး 14,000 ရယူပါ။
